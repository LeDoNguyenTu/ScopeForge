# UX Baseline

The Phase 1 interface establishes the product language for later scanner features.

- Dark, high-contrast application shell designed for long security review sessions.
- Clear separation between navigation, workspace context and security state.
- Mobile layouts are defined alongside desktop layouts.
- Severity colors are supplemental signals, never the only indicator of meaning.
- Empty states explain why data is absent instead of presenting fake scanner results.
- Future findings views will prioritize evidence, affected asset, confidence and remediation over decorative metrics.
