# ScopeForge Delivery Phases

1. Foundation - identity, workspaces, RLS, design system and deployment baseline.
2. Asset control - asset registration, authorization proof, scan jobs and audit events.
3. Code security - SAST, secrets, SCA, SBOM and IaC with R2 artifact storage.
4. Runtime security - authorized web and API DAST with SSRF and execution guardrails.
5. Findings - normalization, correlation, CVSS/CWE, remediation and retesting.
6. Scanner scale - isolated workers, queueing, concurrency budgets and backpressure.
7. Validation - vulnerable labs, precision metrics, false-positive tracking and technical reports.
8. Production polish - responsive QA, threat review, observability, domain hardening and public release.
