# Product Principles

ScopeForge should feel like a security product, not a collection of scanner buttons.

1. Evidence before alert volume.
2. Explain why a finding matters and how it was derived.
3. Keep dangerous operations behind explicit authorization and scope controls.
4. Separate the control plane from scan execution so each can scale independently.
5. Design mobile and desktop experiences together rather than treating responsive behavior as a later patch.
6. Prefer measurable scanner quality, reproducible validation and transparent limitations over inflated capability claims.
