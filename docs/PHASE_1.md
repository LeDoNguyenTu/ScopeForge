Phase 1 establishes the boundaries that later security features depend on.

- Dedicated Supabase project
- Authentication integration
- Profiles and automatic workspace onboarding
- Workspace roles and Row Level Security
- RLS performance optimization

- CI validation
- Deployment, domain and security documentation

Exit criteria:

- Supabase security advisor has no security lints
- TypeScript checks pass
- Next.js production build passes
- Phase 1 is squash-merged to `main`
